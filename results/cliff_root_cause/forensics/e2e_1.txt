### (b) Modifications to upstream files — exhaustive

**solver_mujoco.py (116 lines changed vs upstream).** Two independent layers:

*Layer 1 — carried by the upstream merge ecf4d017 itself (24 lines, authored pre-merge):*
1. **joint_label pre-registration guard** (solver_mujoco.py:744-749): in path-target resolution, return `[]` silently when `builder.joint_label` is empty — USD parsing can call this in a pre-registration pass where no lookup can succeed; resolution re-runs once labels exist. Originated in **1e6c70d0** "Quiet the model-build warning wall for cloned multi-world scenes" (2026-07-01).
2. **Duplicate-actuator skip** (solver_mujoco.py:3164-3171 and 3276-3283): reads `model.joint_target_mode` and skips a native CTRL_DIRECT joint actuator whose DOF is already driven by a JOINT_TARGET (PD) actuator — otherwise its ctrl stays 0 and an affine position actuator acts as a spring-to-zero fighting the PD drive. Escape hatch `NEWTON_KEEP_DUPLICATE_ACTUATORS=1` (solver_mujoco.py:3169). Originated in **5691cd9c** "Skip native actuators duplicating PD joint targets" (2026-07-01).

*Layer 2 — the `_mjw_world_replicas` twin-world plumbing (commits 17edd496 "Derive per-world dims from Newton world count" and b1674820 "Mirror mocap and eq_active rows to twin worlds", both 2026-08-10, merged via 582f6efc). Mechanism: mjw_data is built with `nworld * replicas` worlds while every Newton-side mapping and mjw model field stays primary-sized (model fields broadcast via `field[worldid % shape[0]]`); a subclass sets `self._mjw_world_replicas` BEFORE `super().__init__()`, default 1 leaves every derived dimension unchanged (solver_mujoco.py:3754-3761). Hunk inventory:*
3. `put_data` called with `nworld=nworld * self._mjw_world_replicas` (solver_mujoco.py:7530); nconmax is per-world so naconmax scales with the replicated count.
4. `reset_world_buffers_kernel` launch passes `d.nworld // replicas` as `nworld_primary` so a primary-sized world mask clears replica rows via modulo (solver_mujoco.py:4008; kernel side kernels.py:3248, 3268).
5. `_sync_worldbody_geom_xposes` and `_sync_site_xposes` launch over primary worlds only, then mirror geom_xpos/geom_xmat and site_xpos/site_xmat rows to replicas (solver_mujoco.py:4629-4644, 4654-4671).
