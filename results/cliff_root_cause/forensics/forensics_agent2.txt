=====================================================================
(2) FP32 ROUNDING, SYMBOLICALLY
=====================================================================

Notation: N = fl32(dt_outer) — for dt_outer=0.02 this is the single fp32 value 0.019999999552965164..., with ulp(N) = 2^-29 * 2^... precisely: 0.02 ∈ [2^-6, 2^-5) so ulp = 2^-6-23 = 2^-29 ≈ 1.86e-9; a rounding of a result near N errs by ≤ ½ulp ≈ 9.3e-10.

Boundary entry arithmetic (A:1804-1805): rebase computes next_time = b − b = 0.0 EXACTLY (IEEE x−x=0, A:667), then boundary_advance computes next_time = fl32(0 + dt_outer) = N EXACTLY (A:646, A:1805). Consequence: next_time is the IDENTICAL fp32 constant N at every boundary of the process's life. There is no accumulation channel in next_time at all — the growth the rebase exists to prevent (A:656-662) is prevented exactly, by construction, not approximately.

sim_time entry value: rebase gives fl32(s_end − b) (A:666). At a normal march end s_end ≥ b = N and s_end ≤ N + 1ulp (shown below), so N/2 ≤ s_end ≤ 2N and Sterbenz's lemma applies: the subtraction is EXACT. So sim_time starts each boundary at exactly the previous boundary's landing overshoot, which is either 0 or ~1-2 ulp(N).

Landing arithmetic within a boundary. sim_time accumulates 10-30 fp32 adds (A:445); each add rounds, but intermediate rounding is irrelevant because the clamp re-targets the exact representable N each iteration: r = fl32(N − s) (A:686), then on the clamped accepted step s' = fl32(s + r) (A:445).
- Case s ≥ N/2 (final step spans less than half the boundary — the typical case when carried dt < dt_outer/2): Sterbenz ⇒ r = N − s exactly; then s + r = N exactly and N is representable, so s' = N EXACTLY. The world lands bit-exactly; the strict-< predicate (B:63) sees it landed; rebase yields sim_time = 0.0 exactly. Residual: ZERO, exactly cancelled.
- Case s < N/2 (carried dt > dt_outer/2, so one wide clamped step crosses more than half the boundary): r = fl32(N − s) rounds by ≤ ½ulp(N).
  - If r rounded UP: s' = fl32(s + r) can exceed N by ≤ 1 ulp. World lands; the overshoot (≤ ~3.7e-9) survives the rebase exactly (Sterbenz) and merely shortens the next boundary by that ulp. It is OVERWRITTEN, not accumulated: the next landing recomputes r against N from the current s, so the carried residual after any boundary equals only that boundary's own landing error.
  - If r rounded DOWN, or s+r rounded down: s' < N by ~1 ulp. The world is NOT landed (strict <, B:63). The next iteration's clamp produces remaining ≈ 1-2 ulp(N) ≈ 2-4e-9 — THIS IS THE SLIVER SOURCE. That sliver step then lands exactly (Sterbenz regime), same boundary, +1 iteration.

Conclusion: the residual carried across boundaries is bounded by ~1 ulp(N) ≈ 3.7e-9, has one-boundary memory, and CANNOT grow linearly in boundary count. The clocks' magnitudes never grow (next_time reconstructed exactly; sim_time ∈ [~0, N+ulp]). The only unbounded channel is the max_substeps truncation path: if the flag is force-closed with sim_time < next_time (A:600-607, A:2015), rebase leaves sim_time NEGATIVE (a deficit), and since next_time is re-advanced by the full dt_outer regardless (A:1805), a chronically truncated world's deficit accumulates boundary over boundary — linear growth, but directly visible as resid_max > 0 in telemetry and as unfinished_worlds (A:630-639). Also note env resets zero both clocks together (_reset_worlds A:469-475, called from reset A:2066-2083), wiping any residual.

=====================================================================
(3) THE SLIVER PATH: ideal_dt POISONING
=====================================================================

Setup: _clamp_dt_to_boundary clamps dt to remainder r and sets limited=1 (A:691-694). The attempt is accepted. In _calc_adjusted_step, step = r (post-clamp, A:344).

First, the floor-branch interception: a sub-floor sliver (r < dt_min*1.001) enters the branch at A:360; with e ≤ tol (certain for r ~ 1e-9: step-doubling error scales ~r², r² ≈ 3.5e-18, astronomically under tol=1e-3) it FALLS THROUGH to the normal path (A:383). So the Drake rule runs with step=r either way:
- new_step = 0.9 * r * sqrt(tol / max(e, 1e-30)) (A:395). For e→0 the guard makes sqrt(1e-3/1e-30) ≈ 3.2e13, so raw new_step is huge.
- Deadband does not fire (new_step ≫ 1.2r, A:407).
- Growth clamp bites: new_step = 5r (A:410, MAX_GROW=5 A:293).
- acc = True (e ≤ tol, A:412). consec_rej=0 (A:416).

NEWTON_ADAPTIVE_SLIVER_FIX=0 (default; flag read A:940, passed A:1675, baked into the captured graph): no exemption. dt_ceiling relaxes ×1.1 (A:423-424, harmless), new_step=min(5r, ceiling)=5r (A:429-430), and ideal_dt[world] = 5r (A:431). ONE sliver-accept rewrites the carried ideal_dt to 5× the sliver. For an ulp-sliver r ≈ 1.9-3.7e-9, ideal_dt ≈ 1-2e-8.

Same iteration, _apply_dt_cap floors the working dt: dt = clamp(5r, dt_min, eff_max) = dt_min = 1e-6 (A:86, A:1694-1699) — but ideal_dt itself keeps 5r (the cap kernel never writes it, A:76-88). The world has just landed, so every remaining iteration of this boundary takes the dt≤0 stall branch, which explicitly preserves ideal_dt (A:354-357, comment A:352-354 — that preservation is exactly what makes the poisoned value survive to the next boundary).

Next boundary: the seed cap gives dt = max(5r, dt_min) = dt_min (A:1747-1752). So YES: one sliver-accept poisons the NEXT boundary, forcing the world to restart its march from dt_min = 1e-6 instead of its earned carried dt.

NEWTON_ADAPTIVE_SLIVER_FIX=1: the accepted-and-limited world RETURNS at A:421-422 before A:431 — ideal_dt keeps its pre-sliver value; the sliver cannot poison. Side effects of the early return: the ceiling relax (A:423-424) is also skipped on limited accepts (intended per A:420 "carries no ceiling information"), so a world whose every boundary ends in a clamped landing relaxes its ceiling only on its unclamped accepts. Rejected limited steps are NOT exempted (the check is inside `if acc:`), but a sub-floor sliver cannot reach the reject path at all — the floor branch at A:360 accepts it (ideal_dt=dt_min, A:366) or NaN-guards it; so the fix closes the only real poisoning route.

Un-poisoning and recovery cost (fix=0): the only in-band repair is growth on subsequent accepted attempts. First attempt of the next boundary runs at step=dt_min (floored), so with e ≤ tol it falls through the floor branch and writes ideal_dt = min(5*dt_min, ceiling) (A:395,410,429-431) — recovery compounds from dt_min, ignoring the sub-floor 5r. Growth is ×5 per accepted attempt (A:410), additionally capped by dt_ceiling which relaxes only ×1.1 per accept (A:424,430).
- Ceiling not binding (never rejected recently, ceiling ≈ dt_max/1e6): attempts to recover from dt_min to a healthy h* is ceil(log5(h*/dt_min)): h*=5e-3 → 6 attempts; h*=eff_dt_max=0.02 → 7 attempts. The poisoned boundary itself takes roughly 8-10 iterations (1e-6+5e-6+2.5e-5+1.25e-4+6.25e-4+3.1e-3+... to cover 0.02) versus ~2-4 healthy — and since the march length is the MAX over worlds (flag stays 1 while ANY world is short, B:63/B:80-83 with max_unfinished=0), ONE poisoned world stretches the whole boundary for all worlds.
- Ceiling binding (a prior small-step rejection wrote ceiling = 0.9*step_small, A:427 or A:390): growth is throttled to ×1.1 per accept (A:429-430); recovering a decade of dt takes log1.1(10) ≈ 24 accepted attempts, i.e. tens of boundaries. This is the distinct "ceiling collapse" mechanism; note it requires a REJECTION at a small step (only above-floor rejections lower the ceiling), not a sliver-accept.
- Out-of-band: reset() restores ideal_dt=dt_init and ceiling=ceiling_init for masked worlds (A:471,478, A:2066-2083).

Can poisoning be self-sustaining? The chain needs the boundary's FINAL landing step to be a tiny sliver, which per section (2) requires an earlier wide clamped step (s < N/2 at clamp time, i.e. dt > dt_outer/2) whose landing missed by an ulp. Recovery via ×5 growth tends to produce exactly such wide late steps (dt reaching eff_dt_max=dt_outer), so a poisoned world has elevated odds of re-poisoning — a plausible recurrent limp, but each event costs O(6-10) iterations, not a 7.7× multiplier on its own unless most boundaries are poisoned.
