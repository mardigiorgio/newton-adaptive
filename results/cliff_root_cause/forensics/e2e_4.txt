1b. **Floor-accept branches return before the ceiling relax — a floor-stuck world never relaxes its ceiling.** In `_calc_adjusted_step`, both floor-accept exits return early: the nan-guard refuse at S:393-397 and the finite-but-over-tol commit at S:399-400. The only ceiling-relax line is S:441-442, in the normal accept path. A world pinned at `dt_min` with e>tol therefore accepts forever without ever relaxing `dt_ceiling`; combined with reject-tightening (`ceiling = min(ceiling, 0.9*step)`, S:408/445) and relax only ×1.1 per accepted step (S:321, S:442), climb-out from a crushed ceiling takes ~97 accepted steps (log(1e4)/log(1.1)) — quantified in SCRATCH/forensics_agent3.txt §(2). The sliver-fix accept also returns before the relax (S:439-440), deliberate per the comment (S:438) but a second asymmetry on the same line.

1c. **`mjw_data.time` grows unbounded in fp32, never rebased.** The solver rebases only its own clocks (`_rebase_time` on `_sim_time`/`_next_time`, S:706-724, launched S:1873); no reference to `mjw_data.time` exists anywhere in S (the only `.time*` hits are `opt.timestep`, S:1043-1050/1223/1249). ## 3. The ~8192-magnitude coordinate question

The observed trap is measured, not folklore: SCRATCH/march_guard.csv shows err_max latched at exactly 9.765625e-04 = 2^-10 from boundary 4087 to end-of-run 4269 (193 rows in [9.5e-4, 1.05e-3]), iters=256, with the debt guard bounding resid_max to ~9.5e-3 but not curing the pin. 2^-10 is exactly 1 fp32 ulp in the binade [8192, 16384) (or 2 ulps in [4096, 8192)) — the error kernel's unscaled max|Δq| (S:193-247, state_scale identity S:1086-1090) sits just under tol=1e-3 and freezes the controller in its deadband (S:425-427); this is the mechanism commit 8963c760's floor targets (commit message, and the constant 4.7683716e-07 = 4 ulps at S:230/292). The full-proof run (SCRATCH/march_full_proof.csv, 11106 boundaries ≈ 231 learn-iterations, i.e., well past the 4087-boundary cliff point) shows max iters 48 and zero rows with err == 2^-10.

**qpos layout for the task scene** (per world): Trossen stationary-AI bilateral arm — 2×6 arm hinges + 2×2 gripper carriage joints, all limited (assets.py:70-108, soft_joint_pos_limit_factor=1.0 at assets.py:109) — plus the spatula free joint (3 translations + wxyz quaternion; object at CFG:207-211). No other articulations (table/ground are static, CFG:237).

**Env-origin magnitude, computed**: origins come from `grid_transforms` (interactive_scene.py:176-177) — centered grid, x = -(i-(rows-1)/2)·spacing, y = (j-(cols-1)/2)·spacing (IsaacLab/source/isaaclab/isaaclab/cloner/clone_plan.py:85-100), spacing 2.5 (CFG:385/447), applied as per-env world positions during Newton builder replication (isaaclab_newton/cloner/replicate.py:74-147), so free-joint qpos carries the origin. For the bench's 2048 envs: rows=46, cols=45 → max |x| = 45/2·2.5 = **56.25 m**, max |y| = 44/2·2.5 = 55.0 m, max origin norm ≈ 78.7 m. Even at the cfg default 8192 envs (rows=cols=91): max |x| = 112.5 m. **No legitimate coordinate in this stack reaches 2^13**: translations ≤ ~57 m, hinges limited, quat components ≤ 1. Quantization noise at 56 m is 56·4.8e-7 ≈ 2.7e-5, 40× below tol.

**Illegitimate candidates** (something DID sit in [4096, 16384) for 180+ consecutive boundaries): (i) a flung-but-finite spatula — the controller commits any finite state at the floor (S:399-400), the NaN guard fires only on non-finite/e ≥ 1e9 sentinel (S:393, threshold S:944), and 5 s episodes (CFG:415) at ~10^3 m/s reach 10^3-10^4 m if no termination catches the escape; (ii) an unwrapped spinning coordinate if any limit is ineffective under MuJoCo (8192 rad ≈ 1300 turns); (iii) NOT `d.time` — it never enters the error norm (kernel reads qpos/qvel only, S:1523-1539). The persistence (magnitude stable in one binade for many seconds) slightly favors a resting-at-large-offset state — e.g. an escaped object come to rest far away — over a still-accelerating one.

**Cheap identification — no new kernel needed**: `solver.last_raw_error` is already exposed per world (S:2346-2349). When err_max pins at 2^-10: one host read + argmax → culprit world w; one `mjw_data.qpos.numpy()[w]` row read (21 floats) → the coordinate with |q| ≥ 4096, mapped to its joint via the mj_q_start layout. Two host reads outside the march, run once. For continuous telemetry instead, extend `_log_march_boundary` (already host-reading `_last_error` at S:1961) with `np.abs(qpos).max(axis=0)` — log-gated, zero hot-path cost.
